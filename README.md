# Detektif Gaya — Petualangan Nusantara

Game edukasi interaktif IPAS Kelas 4 / Fase B tentang jenis-jenis gaya dan budaya Nusantara.

## Cara menjalankan

1. Buka file `index.html` di browser.
2. Atau jalankan server lokal sederhana:

   ```bash
   python -m http.server 8000
   ```

   Lalu buka: http://localhost:8000

## Fitur utama

- Home page dengan karakter Detektif Gaya
- Peta petualangan berlapis zona yang bisa dibuka bertahap
- Materi gaya otot, gravitasi, gesek, dan magnet
- Mini-simulasi gaya gesek dan magnet
- Festival Nusantara sebagai mini-game
- Kuis 3 level
- Refleksi dan dashboard guru
- Progress tersimpan dengan `localStorage`

## Catatan

Project ini dibuat tanpa backend dan siap dijalankan secara lokal maupun di GitHub Pages / Netlify.
